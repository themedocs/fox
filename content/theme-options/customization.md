The Fox theme structure is quite simple. Here's where you can make changes:

1. **Theme Customizer**: Dashboard > Appearance > Customize - for global options, typography, layout, color, header, footer..
2. **Post/page settings**: When you edit post/page, you'll see settings below the editor. They're about post layout, show/hide components, post format (video, gallery, slider..)
3. **Category/tag settings**: When you edit category, tag.
4. **User settings**: Dashboard > Users - for changing user description, avatar, social urls.
5. **Page builder**: Dashboard > Appearance > Customize > Page builder
