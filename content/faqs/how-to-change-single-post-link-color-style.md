---

The Fox comes with a couple of post link styles, like following images:

![](/fox/assets/image-17-1024x592-1.png)

![](/fox/assets/image-18-1024x400-1.png)

You can choose/customize post link style in **Customize > Single Post > Single Post Content**:

![](/fox/assets/image-19-1.png)

If you choose “Black Underline”, It’ll always be black color no matter how you set the link color.

For other styles, you can change link color in **Customize > DESIGN > General > Link color**. Here you can change the link hover color as well.

![](/fox/assets/image-20-538x1024-1.png)
