---
title: "Is Elementor necessary for The Fox?"
description: "The current theme version is Fox v6."
---

The current theme version is Fox v6.

In previous versions (ie. Fox v5, v4..), The Fox theme has 2 ways to build hompeage:

1. Using Fox homepage builder (native one)
2. Using Elementor + Fox Framework.

You can choose either 1 of 2 ways but not both.

From version 6, The Fox focuses on the 1st method only (ie. using Fox homepage builder), but still supports customers who used 2nd method. So if you’re an existing customer who has homepage made from Elementor + Fox Framework, don’t worry, there’s no problem with that.

**But if you start building a new site or want to renovate your site, we recommend to use**[**Fox homepage builder**](/fox/page-builder/builder/). You can still use Elementor without any problem, but It’s for sub-pages like About, Contact.. not the homepage.

---

Note that what we are talking about is building the homepage, not About, Contact.. pages. And the 2nd method is about Elementor + Fox Framework. Without Fox Framework, Fox + Elementor is no different than Twenty Twenty theme + Elementor.

---

## **Elementor + Fox Framework**

Please read [this article](/fox/the-fox-v5/the-fox-framework-plugin/) to understand about Fox Framework plugin.

## **Fox + Elementor**

We do not recommend or discourage from using Elementor. It depends on your need and The Fox supports Elementor as the way any other themes do.

## **If you’re a fresh customer, you buy Fox v6 (ie. after August 2023)**

- You don’t need Elementor to build homepage
- You can’t use Elementor to build homepage
- You can use Elementor to build any other pages: About, Contact.. as Elementor usually does. There’s no problem of doing so.

## **If you updated to v6 from Fox v5 and you don’t use Elementor + Fox Framework in v5**

- You don’t need Elementor to build homepage
- You can’t use Elementor to build homepage
- You can use Elementor to build any other pages: About, Contact.. as Elementor usually does. There’s no problem of doing so.

## **If you udated to v6 from Fox v5 and you use Elementor + Fox Framework in v5**

- You can still use Elementor + Fox Framework in v6, there’s no problem and no difference from v5
