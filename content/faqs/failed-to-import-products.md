---
title: "Failed to import products"
description: "This happens when you import any WooCommerce Fox Demo (eg. Fox Classic, Times Writer, Deodar..) but you don’t have WooCommerce plugin installed."
---

This happens when you import any WooCommerce Fox Demo (eg. Fox [Classic](https://fox.themepreview.site/classic/), [Times Writer](https://fox.themepreview.site/times/), [Deodar](https://fox.themepreview.site/deodar/)..) but you don’t have WooCommerce plugin installed.

If you don’t need a shop, please ignore that message. But if you need a shop, please install WooCommerce plugin in **Dashboard > Fox Magazine > Install Plugins** then re-import the demo.
