---
title: "How to backup site settings?"
description: "The Fox uses built-in WordPress setting system in Customizer, hence you can use any Customizer backup plugin to backup your settings."
---

The Fox uses built-in WordPress setting system in Customizer, hence you can use any Customizer backup plugin to backup your settings.

Please install and activate [this plugin](https://wordpress.org/plugins/customizer-export-import/). After that, you’ll see a panel in Customizer namely Export/Import.

There you can export all of your current settings. Later, if you want to restore them, just use Import functionality.
