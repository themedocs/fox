Fox supports WooCommerce.

To set up set up a WooCommerce shop with the Fox theme, it’s 100% same as setting up WooCommerce for any other theme.

Please read the [WooCommerce documentation](https://woocommerce.com/documentation/woocommerce/) for a more detail guide.

**One note**: After install WooCommerce, you’ll find few Fox’s options in *Customize > WooCommerce > Fox Options* section.
