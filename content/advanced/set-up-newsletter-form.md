Fox uses [Mailchimp For WP](https://wordpress.org/plugins/mailchimp-for-wp/) plugin to set up newsletter form. This is a very popular plugin with 1 million+ installations.

**Step 1**: Install that plugin first. You can go to *Dashboard > Fox Magazine > Install Plugin* to install Mailchimp for WP plugin.

**Step 2**: Go to *Dashboard > MC4WP* menu, enter your API key to connect to Mailchimp account. If you have difficutly at this step, please follow read [their instruction](https://www.mc4wp.com/kb/connecting-mailchimp-account-api-key/) to get the key.

![](/fox/assets/image-52.jpg)

**Step 3**: Navigate to *MC4WP > Form* submenu to create your newsletter form.

![](/fox/assets/image-53.jpg)
