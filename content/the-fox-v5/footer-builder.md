There’re 2 types of Footer:

- Classic Footer
- Footer Builder

Classic footer is the built-in Fox footer and you can configure it in **Customize > Footer** panel. The advantage is you have the footer right away and it’s familiar, straight to understand.

Footer builder is the footer that uses FOX Block to build footer. The advantage is you have flexibility to build any layout you want, there’s no limitation like classic footer. This feature is introduced since Fox v4.9

*Some Fox demos are using Footer Builder. Some uses Classic Footer.*

They’re 2 totally independent and separated modules so if you use one kind of footer, you don’t need to worry about the other kind.

To use Footer Builder, you should understand how it works. Footer Builder uses FOX Block, so please take a look at [this article](https://thefox.withemes.com/documentation/fox-block-explained/) to understand how FOX Block works.
