[Elementor](https://wordpress.org/plugins/elementor/) is the most popular page builder right now with 5 millions+ installations. The Fox supports and works well with both Elementor and Elementor Pro in every aspects.

Fox has 20 extra Elementor addon-elements. To use them, you must install **FOX Framework** plugin.

To install **Elementor** and **FOX Framework** plugin, please go to *Dashboard > Fox Magazine > Install Plugins*.

![](/fox/assets/image-2-1024x281-1.jpg)

After installing both *Elementor* and *FOX Framework* plugin, you’ll be able to see a set of FOX Elements for Elementor page builder.

![](/fox/assets/image-3-1024x1021-1.jpg)

If you are not familiar with Elementor, please watch [this tutorial video](https://www.youtube.com/watch?v=Em8oIBGy6bs) from the plugin for having some initial concept. Here’s the [full documentation](https://docs.elementor.com/) of the plugin.
